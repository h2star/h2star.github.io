Xiaoli（小麗）

A private, single-user personal assistant.

What this application does

Xiaoli is a personal assistant that runs privately on its owner's own Mac and is reachable through a private Telegram bot. It is used by one person — its owner — and is not offered to the public, distributed, or sold.

How it uses Google APIs

Xiaoli uses the Google Calendar API for exactly two purposes:

  • Reading the owner's calendar so it can answer questions such as "what's on my schedule tomorrow?"
  • Creating and updating the owner's calendar events when the owner asks it to add or change an appointment.

It requests only two OAuth scopes: calendar.events and calendar.calendarlist.readonly. It does not request access to Gmail, Google Drive, Contacts, or any other Google service.

Where the data goes

Nowhere. Calendar data is used to answer the owner's own questions and is never transmitted to any third party, published, sold, or used for advertising or analytics. There are no other users, so there is no sharing between users.
